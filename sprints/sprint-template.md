## 3. Critérios de Pronto (Definition of Done - DoD)
Uma tarefa só será considerada "100% Concluída" e aceita pela equipe se passar pelos seguintes critérios de qualidade:
1. **Código:** O código foi revisado por outro membro da equipe via Pull Request no GitHub.
2. **Padrão:** O desenvolvimento seguiu rigorosamente os Procedimentos Operacionais Padrão (POPs) do cargo.
3. **Persistência:** Os dados estão sendo gravados ou lidos corretamente no Firebase Firestore, sem dados nulos nos campos obrigatórios.
4. **Ambiente:** O arquivo `development-environment.md` foi atualizado caso alguma nova dependência tenha sido instalada.
