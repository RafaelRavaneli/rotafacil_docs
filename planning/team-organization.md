# Organização e Fluxo de Trabalho da Equipe

A equipe do Rota Fácil é composta por cinco integrantes e está organizada para simular um ambiente ágil de desenvolvimento. Devido à nossa estratégia de focar primeiro na estruturação dos dados e rotas, os esforços iniciais estão concentrados na API e no banco, para posteriormente integrarmos a interface gráfica.

## 1. Divisão de Papéis e Tarefas
* **Equipe de Backend (Rafael e Thiago Carvalho):** Responsáveis pela arquitetura da API em Python (Flask), programação das regras de negócio, desenvolvimento das rotas (CRUD) e segurança do servidor.
* **Equipe de Banco de Dados (José):** Responsável pela modelagem dos dados, estruturação das coleções e gestão da infraestrutura no Google Firebase (Firestore).
* **Equipe de Frontend (Mateus e Thiago Fontana):** Responsáveis pelo design de interface (UI/UX) e pelo desenvolvimento do aplicativo em Flutter (Mobile/Web). No último bimestre, a equipe focará em conectar as telas à API construída pelo backend.
*(Nota: Todos os membros colaboram na revisão de código, planejamento do projeto e documentação).*

## 2. Ciclos de Trabalho
Adotamos o modelo de **Sprints** quinzenais. No início de cada Sprint, a equipe analisa e seleciona as tarefas do Backlog (`backlog.md`) que serão atacadas naquele ciclo.

## 3. Acompanhamento e Ferramentas
* As tarefas são organizadas visualmente através de um quadro **Kanban**, permitindo que todos acompanhem o que está "A Fazer", "Em Andamento" e "Concluído".
* O cronograma geral de entregas ao longo dos bimestres, respeitando a nossa estratégia de fases, é controlado por um **Gráfico de Gantt**.
